# まちを、つなぐ。v0.3.0 今庄地域版

人口減少と歳入減少が続く山間地域を30年間運営する、1人用の自治体経営シミュレーションです。新しい町を一から建てるゲームではありません。すでにある道路・水道・学校・公共施設・住宅・観光資源を引き継ぎ、更新、維持、集約、廃止を組み合わせて将来負担を抑えます。

この版は今庄地域の地形と施設配置を参考にしたゲームです。今庄地域は現在、合併により南越前町の一部です。本作では約3,300人の6地区をひとつの自治体として扱いますが、この自治体運営単位と町長選挙はゲーム上のフィクションです。人口、財政、政策効果、支持率、施設状態はすべてゲーム用の仮定であり、実在自治体の統計、将来予測、政策評価ではありません。

## 起動方法

`index.html` をブラウザで開くだけで遊べます。画像、プログラム、スタイルを1ファイルに内蔵しているため、通信環境がなくても動作します。GitHub Pagesへ置く場合も、この `index.html` をそのまま使用できます。

スマートフォンは横画面を前提にしています。縦向きでは案内を表示して操作を一時停止します。対応端末では右上の全画面ボタンから横向き固定を試みますが、ブラウザや端末が固定を許可しない場合は、端末の回転ロックを解除して横にしてください。

| 湯尾 | 858人 | 小学校、保育所、湯尾駅、工場、高速道路IC |

初期総人口は3,300人です。地区別人口は「今庄 ＞ 湯尾 ＞ 宅良 ＞ 南今庄＝堺東 ＞ 板取」という指定をゲーム向けに配分した値です。板取は地図上でも住宅を2戸だけ描きます。

地図の地区境界は行政界の確定図ではなく、ゲーム操作のために6つへ整理した範囲です。道路・鉄道・河川などは OpenStreetMap を参照し、地形陰影は SRTM を基にしています。ユーザー提供の地図スクリーンショットは配置の参考だけに使い、ゲームへ画像として埋め込んでいません。

地図データの出典：© OpenStreetMap contributors / ODbL。地形標高の出典：SRTM。

## 1年の進め方

1. 航空図で地区の人口、施設、インフラ、観光、支持率を確認します。
2. 「施策を選ぶ」で新規事業を計画します。施策はインフラ、教育、生活、観光、財政の5分野に整理されています。
3. 「予算と事業」で経常収支、基金、借入、工事費、維持費を確認します。
4. 「第○年度を実行」で1年進めます。複数年事業は毎年、費用と実施余力を使います。
5. 年度報告を閉じるとTOPの航空図へ戻ります。4年目ごとには年度報告の前に町長選挙の開票演出が入ります。

30年間を終えるか、選挙で得票率50%を下回ると町政評価書を表示します。

## 地図と表示レイヤー

通常の航空俯瞰に加え、人口密度、高齢化率、空き家、道路健全度、水道老朽度・漏水、公共施設、観光、実施中施策、選挙情勢を切り替えられます。地区名や地形を選ぶと、人口、年齢構成、施設、課題、進行中事業、支持率を表示します。

年度の進行と施策の完成に応じ、住宅、空き家、草地、道路損傷、漏水、工事、引越し、交通、観光客などの表示が変化します。建物1棟や車両1台は複数世帯・複数台を代表する記号で、実際の戸数や個人の移動を1対1で再現するものではありません。

## 人口、財政、インフラ

人口は出生、死亡、転入、転出、町内転居に分けて計算します。住宅を建てただけで人口は増えません。雇用、生活利便、子育て、交通、住宅の空きがそろうほど転入を受け入れやすくなります。

道路、水道、公共施設は毎年劣化します。維持水準を下げると短期の支出は減りますが、事故、生活満足、安全性、将来の更新負担が悪化します。建設事業の費用と、完成後に続く運営・維持費は別に計上します。

教育・道路・水道の分野限定国庫補助は、毎年度52%の確率で公募されます。上限は0.35〜1.20億円で、通常補助後の対象事業費の最大50%へ自動充当します。使途外への流用や翌年度への繰越はできません。

## 住宅とコンパクト化

- 空き家改修：既存住宅を流通させ、入居可能戸数を増やします。
- 町営住宅：2年で24世帯、最大70人を受け入れます。完成後は空室でも維持費がかかり、家賃は入居世帯分だけ入ります。
- 住宅地の造成・分譲：今庄、湯尾、宅良、南今庄で3年かけて80区画を造成します。完成後、転入・町内転居の需要に応じて販売し、分譲収入を臨時収入へ計上します。売れ残りがあっても道路・水道の維持費は続きます。
- コンパクト化：今庄または湯尾を受入先に、最大500人または着手時人口の40%を町内住み替えの対象にします。5年の準備後も、住宅が不足する場合は翌年度以降へ継続します。

コンパクト化による町内移動は町全体の人口を増やしません。移転元の維持範囲は実際に移れた人数に応じて縮小します。移転元で生じた不満は移転先にも持ち込まれ、転居者の支持は4年間かけて新しい生活条件を反映します。

## 施設の維持、統合、廃止

学校は今庄と湯尾だけに設定しています。学校統合もこの2地区間だけで選べます。統合すると送り出し側の施設費を削減できますが、スクールバスと受入校の経費が毎年必要になり、転居と支持低下が起こり得ます。

地区公共施設の廃止は、ゲーム内で公共施設を持つ今庄・湯尾だけが対象です。学校・公共施設の長寿命化は、どちらかが残る地区で選べます。複合化は学校と公共施設の両方が残る地区だけが対象です。施設が存在しない宅良・南今庄・堺東・板取で、架空の公共施設を廃止して財政だけを改善することはできません。

施設再編は初期費用、工期、住民反発、町内転居、町外転出を伴います。予約型交通・通学支援を先に運用すると反発を抑えられますが、交通の運行費は継続します。

## 観光

観光は来訪者数だけでなく、日帰り・宿泊、平均滞在時間、1人当たり町内消費、町内消費率、観光売上、再訪者、関係人口、二地域居住を持ちます。宿泊、飲食・買物、二次交通、景観、Web・SNS、多言語、イベントを組み合わせるほど、滞在と消費へつながりやすくなります。

観光売上は民間の売上です。町には売上の2.5%だけを観光由来の町税として計上します。来訪者増加による清掃・道路負担、住宅の宿泊転用、混雑も発生します。再訪から関係人口、二地域居住、移住・起業へ進む経路はありますが、確実な人口増加策ではありません。

## 選挙

4年ごとに6地区を順番に開票し、地区別得票率と全体得票率を表示します。全体得票率は成人住民数で加重します。財政、人口、生活満足、インフラ、安全、料金、施設再編、交通代替策、直近4年間の実績、地区の反発が影響します。

新しい施策には小さな補正がありますが、選挙前の事業追加だけで簡単に勝てる設計ではありません。得票率が50%未満なら落選となり、その年度でゲームは終了します。

## 保存

自動保存はブラウザ内に保存します。「書き出し」でJSONファイルとして保管でき、「読込」で戻せます。読み込みは現在の町を置き換える前に確認を表示します。

v0.3.0今庄地域版は、地区構成と保存内容が旧8地区版から変わったため、保存先を分けています。読み込めるのはv0.3.0の保存データです。v0.1・v0.2系のセーブは自動変換しません。

## v0.3.0の主な変更

- 8地区の架空町から、今庄、湯尾、宅良、南今庄、堺東、板取の6地区へ全面変更。
- 指定された道路、鉄道、駅、IC、ダム、観光地、生活施設の位置関係を地図へ反映。
- 初期総人口3,300人を、指定された人口順位に合わせて再配分。板取は4人・住宅2戸。
- 今庄地域が現在は南越前町の一部であり、本作の自治体運営単位と町長選挙はフィクションであることをTOP・ヘルプ・制作メモへ明記。
- 学校、公共施設、宅地造成、町営住宅、学校統合、コンパクト化の対象地区を6地区の設定へ合わせて制限。
- 観光地区カードと選挙開票を、6地区が3列×2段で見やすい表示へ変更。
- バージョンをv0.3.0へ更新し、旧8地区版と保存データを分離。

## 動作確認

- 単体HTML内のスクリプト構文、画像内蔵、外部画像・外部スクリプトへの依存がないことを確認。
- 6地区のIDと順序、`SPECS.length === 6`、初期総人口3,300人と地区別配分を確認。
- 30年間の年度進行、人口収支、基金・借入・収支、保存復元、年齢人口の非負を自動検証。
- 宅地造成、町営住宅、学校統合、施設廃止、コンパクト化、分野限定補助、観光税収を個別検証。
- 公共施設のない地区では施設廃止・長寿命化・複合化を選べず、学校統合は今庄・湯尾だけが対象になることを確認。
- 4年ごとの6地区開票、再選・落選、落選後の進行停止を確認。

## モデルの限界

本作は学習・試遊用のシミュレーションです。実際の行政区域、施設定員、道路・水道ネットワーク、建設単価、補助制度、人口移動、住民意見を厳密に再現していません。地図の境界と施設位置にも簡略化があります。現実の政策判断には、最新の統計、現地調査、法制度、住民との合意形成が別途必要です。
